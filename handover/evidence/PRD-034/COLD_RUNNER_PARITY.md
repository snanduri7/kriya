# PRD-034 cold-runner parity - every mandatory external dependency family (owner ruling 2026-11-02, sections 1-6)

Two phases, kept apart (ruling section 6): **PROVISION** may contact authoritative public sources, verifies hashes and builds the frozen inputs; **CERTIFY** (`scripts/certify.sh`) consumes
only frozen inputs and records exactly which it consumed. A missing frozen input makes the canonical pytest stage UNAVAILABLE - the run never discovers a missing package online.

## What a clean hosted runner needs (and does not need)

Needs: outbound network ONLY in the provisioning steps (Maven manifest `fetch`, wheelhouse `provision`, image pull/build, pipx, pinned Maven tarball). Does NOT need: a developer cache,
accidental warm Docker state, a moving public package index during the run, or rate-limit luck.
