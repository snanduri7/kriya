Add an option to the HTML renderer builder that lets callers render a one-line document without the wrapping <p> element. Provide `HtmlRenderer.Builder#omitSingleParagraphP(boolean)`; the default is false and keeps today's behavior unchanged. With the option enabled, a document that consists of a single paragraph is rendered as just the paragraph's inline content: for the input `hi *there*` the rendered result is exactly `hi <em>there</em>` (no <p> tags and no trailing newline). Documents that contain anything other than a single paragraph (several paragraphs, headings, lists, ...) keep their normal rendering.
