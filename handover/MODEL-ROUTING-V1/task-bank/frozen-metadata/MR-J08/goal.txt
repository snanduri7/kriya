When an XML script is written in an annotation such as `@Select("<script>...</script>")`, an unknown element used directly under a top-level `<choose>` is silently ignored: with `<choose><anything></anything><otherwize></otherwize></choose>` no error is reported, while an unknown top-level element such as `<chooze>` fails with "Unknown element <chooze> in SQL statement.". A typo like that is very hard to find. Make an unknown element nested inside `<choose>` (anything other than `<when>` and `<otherwise>`) raise the same kind of error as an unknown top-level element: a BuilderException whose message is `Unknown element <NAME> in SQL statement.` with NAME being the unknown element's name (for the example above `Unknown element <otherwize> in SQL statement.`). Valid scripts must keep working.
