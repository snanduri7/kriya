`marshmallow.validate.URL` rejects every URL whose host name is an internationalized domain name (non-ASCII letters), and there is no way to accept them. A host name alone without a scheme (`münchen.de`, `তৌহিদুর.বাংলা`) must still be rejected with a `ValidationError` in the default configuration, and the behaviour for ASCII URLs must not change.
