For a fully qualified name with more than two dotted parts, `Identifier.get_real_name()` returns the wrong part. For example `db1.table1.a1` (a column qualified by database and table) gives `table1` instead of `a1`, and `get_name()` is affected the same way. Make `get_real_name()` return the last component of a qualified name (`db.schema.tbl.col` -> `col`, `a.b.c` -> `c`), including when the identifier has an alias (`x.y.z AS w` -> `z`). Two-part names such as `a.b` and unqualified names must keep their current results.
