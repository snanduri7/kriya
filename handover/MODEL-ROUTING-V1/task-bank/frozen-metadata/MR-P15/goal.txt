`boltons.funcutils.wraps(donor)(target)` builds a shim function that has `donor`'s signature and calls `target`. When `target` declares a parameter as keyword-only but `donor` accepts that parameter positionally, the shim passes it positionally and the call fails with a `TypeError`. Failing cases: with `def g(a, b)` and `def f(a, *, b)`, `wraps(g)(f)(3, 4)` raises instead of returning `f(3, b=4)` (7), and `wraps(g)(f)(3, b=4)` must also work; with a donor that has varargs, `def g(a, b, *va)` and `def f(a, *va, b)`, `wraps(g)(f)(1, 2, 3)` must return `(1, (3,), 2)`. The case where the donor's parameter has a default already works and must keep working (`def g(a, b=10)` and `def f(a, *, b=1)`: `wraps(g)(f)(3)` is 30 and `wraps(f)(g)(3)` is 3). Make the generated shim pass every argument that the wrapped callable accepts only as keyword-only as a keyword argument, whatever the donor's signature looks like. If the wrapped callable's signature cannot be introspected (for example `update_wrapper(map, g)`), wrapping must keep working using the donor's signature alone.
