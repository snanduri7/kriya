XML.toJSONObject() throws an uncaught java.lang.IllegalArgumentException (a runtime exception rather than a JSONException) when the XML contains a numeric character reference that does not denote a valid character, for example `<a>&#x110000;</a>` or the decimal form `&#1114112;`; the same happens inside attribute values such as `<a b="&#x110000;"/>`. Parsing untrusted XML should fail with a controlled JSONException instead. Numeric character references that are not valid XML characters (out-of-range code points, and surrogate code points such as &#xD800;) must be rejected with a JSONException in element content and in attribute values. Valid references such as &#65; or &#x1F600; must keep decoding as before.
