When a command or group name is not given explicitly, click derives it from the decorated function's name (underscores become dashes). It is common to name the function with a suffix to avoid clashing with a helper of the same name, e.g. `init_data_command` wrapping `init_data`, which currently produces the command name `init-data-command`. Strip the conventional suffixes `_command`, `_cmd`, `_group` and `_grp` when deriving the name, so that `init_data_command` becomes `init-data` (and likewise for groups). Names that are given explicitly must be left untouched.
