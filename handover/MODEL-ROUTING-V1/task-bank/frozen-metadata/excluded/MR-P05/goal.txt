With the `attr_list` and `toc` extensions, a heading whose id is set with backslash escapes, e.g. `## Foo { id="\*Foo\*" }`, ends up with an inconsistent id: the heading itself gets `*Foo*` (so its permalink is `#*Foo*`) but the table of contents link contains an internal placeholder form of the escaped characters (something like `#%0242%03Foo%0242%03`), so the link does not point to the heading. Make the ids that `toc` reports for such headings (in the table of contents and tokens) match the heading's actual id, with the backslash escapes handled like in other attribute values.
