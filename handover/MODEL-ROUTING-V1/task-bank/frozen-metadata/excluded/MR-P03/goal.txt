Jinja's `{% set %}` supports tuple assignment to plain variables (`{% set a, b = b, a %}`) but not to namespace attributes: `{% set ns.a, ns.b = ns.a + 1, ns.b + 1 %}` fails with `TemplateSyntaxError: expected token 'end of statement block', got ','`. Support assigning to several namespace attributes with a tuple target, so that after `{% set ns = namespace(a=12, b=36) %}{% set ns.a, ns.b = ns.a + 1, ns.b + 1 %}` the template renders `13|37` for `{{ ns.a }}|{{ ns.b }}`. Single namespace-attribute assignments and ordinary variable tuple assignment must keep working.
