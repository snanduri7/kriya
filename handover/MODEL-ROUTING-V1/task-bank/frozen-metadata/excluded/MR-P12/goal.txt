An option declared with `is_flag=False` and a `flag_value`, for example `@click.option("--name", is_flag=False, flag_value="Flag", default="Default")`, no longer works as the documentation says. Since Click 8.3.0, passing `--name` with no value exits with "Error: Option '--name' requires an argument." instead of using `flag_value`. Restore the documented behaviour: such an option may be omitted (the default is used), given on its own as a bare flag (the `flag_value` is used), or given with an explicit value (that value is used). It must work for a `str` option (`flag_value="FlagValue", default="Default"`) and for an `int` option (`type=int, flag_value=1, default=0`: omitted gives 0, bare `--theflag` gives 1, `--theflag 2` gives 2). Options with `is_flag=False` and no `flag_value` must continue to require an argument.
