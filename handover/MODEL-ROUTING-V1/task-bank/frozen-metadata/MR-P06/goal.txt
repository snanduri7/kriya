Reference links used inside a heading are not rendered in the table of contents: for the document `# [baz][ref]` plus the definition `[ref]: /quux`, the heading is rendered as `<h1 id="toc_2"><a href="/quux">baz</a></h1>` but the corresponding table-of-contents entry shows the raw text `[baz][ref]`, while inline links in headings already render correctly (without the HTML). Make the table of contents entries render reference links the same way (`<li><a href="#toc_2">baz</a></li>` for the example), for the TOC directive and wherever else mistune builds TOC entries from heading text.
