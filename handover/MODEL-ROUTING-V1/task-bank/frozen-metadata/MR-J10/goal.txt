`ThreadPoolBulkheadConfig.from(baseConfig)` returns a builder that writes through to the base configuration instead of working on a copy: configuring the builder changes the base config, and `build()` returns the very same instance. Other config classes (BulkheadConfig, RateLimiterConfig, TimeLimiterConfig, CircuitBreakerConfig) copy the base values. Make `from(baseConfig)` start from a copy of all the base config's values so that the base config stays unchanged and the built config is a different instance carrying the base values (including context propagators) plus any overrides.
