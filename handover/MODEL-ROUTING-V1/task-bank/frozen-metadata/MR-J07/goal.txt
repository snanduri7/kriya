The generated mapper code does not compile when a `@Condition` method is used as a source presence check for a collection property that is mapped through an adder method (collection mapping strategy ADDER_PREFERRED). For a mapper like `CustomerPersonDTO toDTO(CustomerPerson entity)` with a `@Condition default boolean isLazyLoaded(Collection<?> sourceCollection)` method, the generated implementation refers to a variable that does not exist (javac reports "cannot find symbol ... variable address"). Fix the generated code so such mappers compile and the condition is honored: when the condition says the source collection should be skipped the adder is not invoked, otherwise the elements are added.
