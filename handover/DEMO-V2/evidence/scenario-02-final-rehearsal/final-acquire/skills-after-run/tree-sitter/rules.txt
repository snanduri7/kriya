# Add architectural rules here (one per line)

Tree-sitter parsers are generated based on language definitions and provide Abstract Syntax Tree (AST) representations of source code.
The root node of an AST generated by Tree-sitter represents the entire program or module.
Tree-sitter JavaScript bindings can be installed using npm with the command 'npm install tree-sitter tree-sitter-python --legacy-peer-deps'.
In Tree-sitter, each node in the AST has a 'type' property that indicates the syntactic construct it represents (e.g., 'function_definition', 'identifier').
Tree-sitter AST nodes have a 'children' array property that contains child nodes of the current node.
Tree-sitter AST leaf nodes may contain text content via the 'text' property which holds the actual source code snippet for that element.
