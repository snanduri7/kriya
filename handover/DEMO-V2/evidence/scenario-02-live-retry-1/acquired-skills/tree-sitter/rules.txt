# Add architectural rules here (one per line)

Tree-sitter parsers are generated based on language definitions and provide an Abstract Syntax Tree (AST) representation of source code.
The root node of a Tree-sitter AST represents the entire program or module.
Tree-sitter AST nodes have a 'type' property that indicates the syntactic construct (e.g., 'function_definition', 'identifier', 'call_expression').
Tree-sitter AST nodes have a 'children' array containing child nodes, enabling recursive traversal of the tree structure.
Tree-sitter AST leaf nodes may contain a 'text' property with the actual textual content of the code element they represent.
In JavaScript projects, Tree-sitter can be used via npm-installed packages like 'tree-sitter' and 'tree-sitter-python'.
The Tree-sitter parser in JavaScript is initialized using new TreeSitter() and setLanguage() with a language-specific parser module.
Tree-sitter ASTs are generated by calling the parse() method on a parser instance with source code as input.
